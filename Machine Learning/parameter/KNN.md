**KNN — Important Parameters**

| Parameter | Meaning | Example |
|---|---|---|
| `n_neighbors` | Number of nearest neighbors | `KNeighborsClassifier(n_neighbors=5)` |
| `weights` | How neighbors contribute | `weights="distance"` |
| `metric` | Distance calculation method | `metric="euclidean"` |
| `p` | Power parameter for Minkowski distance | `p=2` |

**Most important:** `n_neighbors`, `weights`, `metric`

**Linear Regression — Important Parameters**

| Parameter | Meaning | Example |
|---|---|---|
| `fit_intercept` | Whether to calculate the intercept | `LinearRegression(fit_intercept=True)` |
| `positive` | Forces coefficients to be positive | `LinearRegression(positive=True)` |

**Main attributes:**

| Attribute | Meaning |
|---|---|
| `coef_` | Slope/coefficient |
| `intercept_` | Intercept |
| `score()` | R² score |
